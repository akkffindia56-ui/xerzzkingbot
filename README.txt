XERZZ KEYSHOP — VS CODE

1) Python 3.10+ орнатыңыз.
2) Осы папканы VS Code арқылы ашыңыз.
3) Терминалда орындаңыз:
   pip install -r requirements.txt
4) .env.example файлын .env деп көшіріңіз.
5) .env ішіне BOT_TOKEN, API_KEY және MASTER_KEY мәндерін енгізіңіз.
6) Ботты сатылым тобына қосып, хабарлама жіберу құқығын беріңіз (ең дұрысы — әкімші).
7) Топ ішінде /id командасын жіберіңіз. Бот көрсеткен Chat ID-ді .env ішіндегі SALES_GROUP_ID жолына жазыңыз.
8) Фото керек болса, STORE_BANNER_URL ішіне ашық қолжетімді сурет URL-ін немесе STORE_BANNER_FILE ішіне жергілікті сурет жолын жазыңыз.
9) Ботты іске қосыңыз:
   python bot.py

API:
- Барлық берілген product_id мәндері products.py файлына енгізілді.
- Сатып алу сұранысында action=buy, product_id, duration және quantity=1 жіберіледі.
- Сағаттық тарифтер API-ге "1 Hours" форматында, күндік тарифтер "1 Day" / "7 Days" форматында жіберіледі.
- android_id тек қажет болатын Device-Bound / V1 өнімдерінде ғана берілуі тиіс. Қазір ботта автоматты түрде жіберілмейді; егер API оны міндетті десе, сол өнімге жеке Android ID енгізу логикасын қосу керек.
- Бот API JSON жауабынан key/license/code/token сияқты өрістерден кілт іздейді. Егер жеткізуші басқа JSON құрылымын қайтарса, нақты жауапқа қарай parser-ді бейімдеу қажет.
- API кілті анықталмаса, бот жалған сәттілік көрсетпейді, API жауабын жеке чатқа шығарады.
- Кілт сатып алушыға жеке жіберіледі және SALES_GROUP_ID орнатылса, топқа да жіберіледі. Кілт tg-spoiler арқылы жабық көрсетіледі.

ҚАУІПСІЗДІК:
- .env файлын ешкімге жібермеңіз және GitHub-қа жүктемеңіз.
- Бұрын чатқа жіберілген API_KEY және MASTER_KEY мәндерін API панелінен жаңартыңыз.
- Telegram топта ботқа хабарлама жіберу құқығы болуы керек.
